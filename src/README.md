# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share activities with friends using Facebook, X, WhatsApp, or Copy link on any
  activity card, without logging in. Shared links open the activity search with
  that activity's name already filled in; clear the search to browse all activities.
  If copying is unavailable, select and copy the displayed link manually.
  Only the activity name and link are shared, not student or teacher information.
